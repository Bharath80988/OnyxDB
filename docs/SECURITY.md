# Security Policy

## Reporting Vulnerabilities

The ForgeQL team takes security seriously. If you discover a security vulnerability within ForgeQL, please report it privately rather than creating a public GitHub issue.

### How to Report
Please email security concerns to **security@forgeql.io** or open a confidential security advisory on GitHub.

Include as much detail as possible:
1. Type of issue (e.g. buffer overflow, authentication bypass, SQL/FQL injection).
2. Step-by-step instructions to reproduce the issue.
3. Proof-of-Concept payload (if available).

### Response SLA
* **Initial Acknowledgment**: Within 48 hours.
* **Triage & Remediation Plan**: Within 5 business days.

Thank you for keeping ForgeQL safe!
